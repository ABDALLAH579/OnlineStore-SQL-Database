# Online Store Database

## Project Overview
This project focuses on designing and creating an Online Store database using Microsoft SQL Server.

## Project Contents
- Database Creation
- Tables Design
- Primary Keys & Foreign Keys
- Relationships between Tables
- Constraints
- Data Insertion
- SQL Queries

## Tools
- Microsoft SQL Server
- SQL

## Objective
To practice database design, SQL queries, and relationships between tables in a real-world online store scenario.
